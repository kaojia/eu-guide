補齊 PID 商品編碼

2026/11/1 起，從歐盟境外直寄歐盟買家、貨值 €150 以下的訂單，報關都要附 PID。這頁教你先判斷要不要做，再用品類刊登資訊報告找出缺漏、一次補齊。

00

先確認：我需要做嗎？

PID 規定只看「貨從哪裡出發」，不是看你賣哪一站。

你的出貨方式要不要補 PID
貨放在歐盟倉（EFN／Pan-EU／多國庫存），出給歐盟買家不適用：歐盟境內出貨，沒有 €3、€2，也不用報 PID
貨放在英國倉，用遠程配送（Remote Fulfilment）出給歐盟站買家要補：亞馬遜會從商品目錄抓 PID 報關，你要確保目錄資料齊全
從台灣或其他歐盟境外地點自發貨（FBM）直寄歐盟買家要補：而且每次出貨都要把 PID 交給承運人（見 05）
貨值超過 €150 的訂單不用報 PID，但 €2 海關處理費照收，FBM 也一樣要用 DDP（完稅後交貨）出貨。就算目前全部用歐盟倉，之後想開遠程配送或 FBM，建議也先把 PID 補好，可以順便讓刊登資料更完整。
01

三種 PID 各填什麼

每個適用的商品都要有 M-PID 和 NS-PID；S-PID 是「商品有這個編碼就必填」。

編碼是什麼後台對應欄位要求
M-PID
商家 PID		商品的 ASIN亞馬遜自動帶入，不用填必填（自動）
NS-PID
非標準 PID		製造商給的零件號或型號Part number／零件號、Model number／型號必填。製造商沒有給的話，可以拿 S-PID（EAN 等）來填
S-PID
標準 PID		EAN／GTIN／UPC；出版品是 ISBN／ISSNProduct ID／商品編碼（外部商品編碼）商品有這個編碼就必填。只有 UPC／EAN／GTIN 算數
  1. 自有品牌、自己就是製造商：你內部用的產品型號就是 NS-PID，填進 Model number 即可。
  2. 有 GTIN 豁免、沒有條碼：S-PID 這格可以空著，但 NS-PID（型號或零件號）一定要有。
  3. 手工品豁免：HS 編碼 4420、4602、4802、5702、5804、5805、7013 系列可免 S-PID，NS-PID 仍要有。
  4. 醫療器材與藥品：S-PID 有指定格式（MDR／IVDR 器材填 UDI-DI；尚未適用 UDI-DI 的舊器材在 2026/11/27 前填 CELEX 號「32017R0745」或「32017R0746」；藥品填 AI 01.8 產品碼）。這類商品請直接對照官方說明頁。
02

找出缺 PID 的商品

用品類刊登資訊報告（Category Listings Report，CLR）一次看全部刊登。這份報告是分站點的，有在哪幾站上架，就要每站各下載一份。

  1. 後台主選單 → Products（商品） → Product reports（商品報告）。
  2. 在 Request an inventory report（申請庫存報告） 選 Category Listings report（分類商品報告）。看不到這份報告的話，要聯絡銷售夥伴支援開權限。
  3. Listings created after（指定日期後創建的商品信息） 留空。
  4. Select status filter（選擇狀態篩選器） 選 ALL（全部）。
  5. 按 Request report（請求報告），狀態變成 Done（已完成） 後按 Download（下載），會下載一個或多個 Excel 檔。
  6. 每個檔案打開 Template（模板） 分頁，找 Product ID、Part number、Model number 三欄，看哪幾列是空的。看不懂欄位名稱的話，把第 5 列取消隱藏就會顯示英文欄名。

  2. Part number／Model number：就是 NS-PID，兩欄至少要有一個有值。
報告只包含你自己提交過的資料，不含 ASIN 的其他來源資料，也不含已刪除的刊登。所以報告裡是空的，就代表你的刊登沒有提供。

下載不了 CLR 的話，參考官方說明頁「下載分類商品報告」。

03

用報告批量補齊（官方推薦）

直接在剛下載的 CLR 裡補，再整份上傳回去。

  1. 在 Template 分頁把缺漏的 Product ID、Part number、Model number 補上。
  2. 最重要的一步：每一列的 Listing action（商品操作） 都選 Edit (partial update)（編輯（部分更新））。
  3. 存檔前檢查 Quantity（庫存數量）和 Your price（商品售價）兩欄是不是最新的，避免把舊數字一起上傳回去。
  4. 上傳：Products（商品） → Add products（添加商品／批量上傳商品） → Spreadsheet（表格） 分頁 → Upload file（上傳文件） → Submit products（提交商品）。
  5. 每個站點的檔案各做一次。
當天下載、當天改、當天上傳。官方特別提醒不要隔天才上傳：中間有賣出或調價，舊檔案裡的庫存和價格就會把現況蓋掉。
04

少量商品：逐筆補

只缺幾個 SKU 的話，直接在刊登頁面改比較快。

  1. Products（商品） → Manage products（管理商品）。
  2. 在缺編碼的刊登旁按三個點 → Edit listing（編輯商品）。
  3. Product identity（商品身份信息） → External product ID（外部商品編碼）：下拉選 UPC／EAN／GTIN，填入編碼。
  4. Product details（商品詳情） → 右上角 Filter attributes（篩選屬性） 選 All（全部），才會出現型號和零件號欄位。
  5. 填 Model number（型號）或 Part number（零件號） → Submit（提交）。
  6. 其他缺漏的刊登重複第 2～5 步。
05

FBM：出貨時還要再交一次

FBA 遠程配送由亞馬遜從商品目錄抓 PID 給承運人；FBM 是你自己負責把 PID 交給承運人，刊登裡有填也一樣。

你怎麼買運單要做什麼
用購買配送（Buy Shipping）買運單時逐件填零件號或型號（即使刊登裡已經有）。11/1 起沒填就買不了運單。亞馬遜會把 PID 和亞馬遜的 IOSS 編號一起傳給承運人。
自己找承運人貨值 ≤ €150：只能用亞馬遜認可的承運人，確認發貨時從下拉選單選（不能手動輸入承運人名稱，API 確認發貨也一樣）。確認後把每件商品的 ASIN、PID、亞馬遜 IOSS 編號和其他清關資料交給承運人，交付格式先跟承運人確認。
  1. 所有 FBM 訂單，不論貨值都要 DDP（完稅後交貨）：買家收貨時不能再被收任何關稅或稅費。
  2. 報關單上不能把買家列為申報人；貨值 > €150 也不能把亞馬遜列為申報人。被海關查到可能駁回報關、影響該商品的跨境銷售權限。
  3. €2 海關處理費由承運人開發票向你收，再由承運人繳給歐盟海關。
  4. 慣用的承運人不在認可名單上：請承運人自己寫信到 eu-customs-reform-carrier-self-request@amazon.com 申請，附上公司法定名稱、設立國家、地址、聯絡人全名和 email。
06

補完後怎麼驗證

  1. 上傳後等系統處理完，重新下載一份 CLR（同樣日期留空、狀態選 ALL）。
  2. 在 Template 分頁確認每一列的 Product ID、Part number／Model number 都有值。
  3. 有在多個歐盟站上架的話，每站各驗一次。
11/1 之後還沒補齊的商品，跨境訂單可能清不了關，該商品在亞馬遜的銷售權限也可能受影響。越早補越好。
07

最常翻車的四件事

  1. 上傳 CLR 時沒選「部分更新」：整份刊登被覆蓋，庫存和價格回到檔案裡的舊值。
  2. 只下載一個站點的報告：CLR 是分站點的，德國站補了，法國站還是空的。
  3. 以為刊登有填就好（FBM）：用購買配送時還是要在買運單時再填一次；自己找承運人要另外把 PID 交給對方。
  4. 把 €3 和 €2 當成二選一：€2 是疊加在 €3 上面，≤ €150 每個品項／稅則列合計 €5；> €150 也要收 €2。
